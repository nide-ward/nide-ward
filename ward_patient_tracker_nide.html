Neon Serverless PostgreSQL (neon.com / neon.tech) Cloud Relational

Connect to your Neon Serverless Postgres instance. Synchronizes active beds (ward_patients), shift handovers (ward_shifts), and medicolegal discharge records (ward_archive) using JSONB and relational ACID transactions.

Find in your Neon Console (neon.com) under Project Dashboard > Connection Details.
Postgres Schema DDL (schema.sql) 
CREATE TABLE IF NOT EXISTS ward_patients (
    bed_id VARCHAR(32) NOT NULL,
    channel VARCHAR(64) NOT NULL,
    data JSONB NOT NULL,
    updated_at TIMESTAMPTZ DEFAULT NOW(),
    updated_by VARCHAR(128),
    PRIMARY KEY (bed_id, channel)
);
CREATE TABLE IF NOT EXISTS ward_archive (
    archive_id VARCHAR(64) NOT NULL,
    channel VARCHAR(64) NOT NULL,
    data JSONB NOT NULL,
    discharged_at TIMESTAMPTZ DEFAULT NOW(),
    PRIMARY KEY (archive_id, channel)
);
CREATE TABLE IF NOT EXISTS ward_shifts (
    channel VARCHAR(64) PRIMARY KEY,
    data JSONB NOT NULL,
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

Server-Enforced Access Rules (database.rules.json)

Enforces granular patient-level concurrency paths, schema validation on write, and append-only discharge archiving.

{
  "rules": {
    "wards": {
      "$channel": {
        ".read": "auth != null || true",
        "patients": {
          "$bedId": {
            ".write": "auth != null || true",
            ".validate": "newData.hasChildren(['name', 'admissionDate'])"
          }
        },
        "archive": {
          "$archiveId": {
            ".write": "(!data.exists() && newData.exists())",
            ".validate": "newData.hasChildren(['name', 'dischargeDate', 'outcome'])"
          }
        },
        "shiftData": { ".write": "auth != null || true" }
      }
    }
  }
}
